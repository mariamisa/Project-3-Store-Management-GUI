# 🛍️ STYLEVA - E-Commerce Fashion Store

STYLEVA is a modern e-commerce web application for clothing and accessories, built with React and Redux. It provides a smooth shopping experience with full cart functionality and dynamic product management.

---

## 🚀 Live Demo
👉 [https://store-mariam.netlify.app/]

---

## 📌 Features

- 🛍️ Browse clothing and accessories products
- 🔍 View product details
- 🛒 Add products to shopping cart
- ➕➖ Increase or decrease item quantity
- 🗑️ Remove items from cart
- 💰 Automatic total price calculation
- 📱 Fully responsive design (mobile & desktop)

---

## 🧠 Tech Stack

- React.js
- Redux Toolkit
- React Router
- JavaScript (ES6+)
- CSS / Styled Components

---

## 🛒 Key Features Breakdown

### Product Listing
Displays a collection of fashion products with a clean and modern UI.

### Cart Management (Redux)
- Add items to cart
- Remove items from cart
- Update quantity dynamically
- Maintain global cart state using Redux Toolkit

### State Management
All cart logic is handled using Redux for scalable and predictable state updates.

---

## 🎯 Purpose of the Project

This project was built to practice and demonstrate:

- React component architecture
- Redux state management
- Real-world e-commerce functionality
- UI building for scalable frontend applications
